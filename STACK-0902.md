# Spec integration 0902 — stack index

This file exists so the integration branch has a commit of its own and the
umbrella pull request can stay open while the stack is reviewed. It carries no
specification text and is deleted before this branch merges.

**Nothing in this stack is ratified.** Each change is its own draft pull request
targeting this branch. Accepting a change means merging its sub-PR here;
rejecting one means closing it. What reaches `main` is whatever this branch
holds when the owner is done.

The ordered list of sub-PRs, with one-line summaries and decision status, is in
the umbrella pull request body. The full reasoning per row — proposed text,
alternatives, recommendation, confidence — is in the decision sheet at
`local/SPEC-INTEGRATION-DECISIONS-0902.md`, which is gitignored and local to the
owner's checkout.
